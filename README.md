# Data Pipelines with Azure - Data Integration Pipelines for NYC Payroll Data Analytics

This repository contains the Azure Data Factory project configuration associated with "Data Pipelines with Azure"
Udacity course, which is part of the "Data Engineering with Microsoft Azure" nanodegree.

The GitHub.com project is located at [cariad-robert-abel/udacity-azure-nyc-payroll-project](https://github.com/cariad-robert-abel/udacity-azure-nyc-payroll-project).

## Azure Data Factory

The configuration files in this repository were published using the Azure Data Factory GitHub connector and represent
the latest state of datasets, data flows, pipelines in the NYC Payroll Data Analytics project.
